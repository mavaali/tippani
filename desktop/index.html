First time here?

Tippani uses Azure CLI for Microsoft sign-in. It opens your browser or account picker and renews access while the app stays open. No Node.js or npm needed.

Your token stays in memory only. Enter it again after quitting or stopping a review. Never put a token in the URL.

How do I get an access token?

GitHub: open Settings → Developer settings → Personal access tokens → Fine-grained tokens. Select the repository, Contents (Read), and Pull requests (Read and write). For file editing, Contents also needs write access. Your organization may need to approve the token or authorize SSO.

Tokens grant your account's permissions. Use the shortest practical expiry and only the repositories you need. Revoke a token on the provider's website if you lose it. Ask your repository owner if token creation is restricted.

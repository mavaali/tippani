# v1.8.2 - Clear local and offline recovery

Tippani now makes it obvious when Discovery is running without a repository-host
connection.

## Fixed

- Discovery displays a prominent **Local only** notice when Tippani was launched
  with `--local-repo`, or **Offline** when it was launched from cached review
  data.
- The notice explains which remote capabilities are unavailable, including pull
  requests, work items, shared comments, fresh content, and remote publishing.
- For Azure DevOps clones, Tippani reads the clone's `origin` and provides a
  copyable command with the exact organization, project, and repository needed
  to restart online.
- Connected portals continue to open Discovery without the warning.
